SPG 1.0 — GitHub Pages Deploy

Este pacote é derivado do SPG_1.0_FINAL_MASTER.html sem recompressão dos assets.
Somente 11 data URIs maiores foram externalizados em arquivos ao lado do index.html para manter o index abaixo do limite de upload web do GitHub.

UPLOAD:
1. No repositório spgames, clique em “uploading an existing file”.
2. Arraste TODOS os arquivos desta pasta (index.html, .nojekyll e spg_asset_*.png/webp).
3. Commit message: Publish SPG 1.0 FINAL
4. Commit directly to main.
5. Settings > Pages > Deploy from a branch > main / (root) > Save.
